# Skills

Colección de skills para revisar y mejorar código, organizada como [mattpocock/skills](https://github.com/mattpocock/skills).

## Flujo para mejorar un proyecto

1. [`/code-review`](skills/engineering/code-review/SKILL.md) — identificar defectos y problemas de mantenimiento.
2. [`/improve-codebase-architecture`](skills/engineering/improve-codebase-architecture/SKILL.md) — explorar oportunidades arquitectónicas.
3. [`/grill-me`](skills/productivity/grill-me/SKILL.md) — resolver las decisiones mediante una entrevista.
4. [`/codebase-design`](skills/engineering/codebase-design/SKILL.md) — diseñar módulos más simples, sólidos y fáciles de probar.

## Estructura

- [Engineering](skills/engineering/README.md) — revisión, arquitectura, diseño y configuración.
- [Productivity](skills/productivity/README.md) — entrevista y toma de decisiones.

**Dependencias incluidas:** `grilling` (motor de `grill-me`), `domain-modeling` (usado durante la auditoría arquitectónica) y `setup-matt-pocock-skills` (configuración inicial para las skills de ingeniería). La configuración se realiza en el **repositorio del proyecto donde se usen las skills**, no en este catálogo.
